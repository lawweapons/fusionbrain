## Patterns & Gotchas

- **"One thou steps" is the critical threading detail.** The document name explicitly calls out 0.001" incremental infeed passes on the thread op. This was the iterated solution (v3) — do not increase infeed step size without re-validating thread form and tool deflection.
- **500 RPM is a deliberate conservative choice** — likely driven by threading synchronization requirements and/or material toughness. Do NOT blindly increase RPM for the threading op; the spindle encoder sync is the limiting factor, not surface speed.
- **Op 2 (roughing) uses compensation = Control vs. all others using Computer.** This is a deliberate override — the control is handling cutter comp offset during roughing. Verify your control supports this before posting.
- **Roughing and finishing feeds are identical at 40 IPM.** There is no feed reduction for finishing. The "finish" quality is achieved through the reduced stepover/DOC, not a slower feed rate.
- **Post-thread finishing pass (Op 5)** is a non-obvious addition. It runs the general turning tool over the OD after threading — confirm this pass clears the thread crests and is only touching non-threaded diameters (relief, shoulder, shank), or it will damage the thread.
- **SFM values in the digest are inconsistent** (Op 1 shows 250 SFM; Ops 2/3/5 show ~3000 in/min which is a raw formula artifact). The **operative value is 500 RPM** — treat SFM as informational only for this program.

## How to Adapt This for a New Part

- [ ] **Confirm material match** — 500 RPM / 40 IPM / Ti-coated insert is tuned for the original material. Aluminum would run 3–5× faster; harder stainless may need slower feed.
- [ ] **Confirm thread spec** — 1/2"-28 pitch (0.03571"/rev) is hardcoded via tool pitch. Change thread tool and pitch parameter if thread spec differs.
- [ ] **Verify "one thou" infeed steps** are appropriate for your thread depth and material — shallower infeed = more passes = longer cycle but better tool life and form accuracy.
- [ ] **Check Op 2 compensation mode (Control)** is supported on the target CNC lathe before running.
- [ ] **Confirm Op 5 (post-thread finish) geometry** clears thread OD — if the new part has a longer threaded zone, this pass may need to be suppressed or its geometry boundary adjusted.
- [ ] **T1 (general turning)** maps to: facing, OD roughing, OD finishing, shoulder cleanup. **T2 (thread tool)** maps to: threading only. No grooving, boring, or parting ops are present — add as needed.
- [ ] **Stock definition** is auto-bounding-box — verify it captures all features if the new part has significantly different proportions.
